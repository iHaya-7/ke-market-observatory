1. Create the website repository

Use a GitHub account you are permitted to use. Create a public repository called ke-market-observatory, with main as the default branch.

Upload the contents of this extracted folder. Do not upload the ZIP as a single file. Include .github/workflows/refresh-and-deploy.yml; on Windows, enable hidden items or create this path with GitHub's Add file > Create new file.

A public repository and website can be viewed by others. Keep Ministry documents, personal contacts, internal salary details and credentials out of this project.

2. Enable publishing

  1. Open Settings > Pages and set the build source to GitHub Actions.
  2. Where allowed, check Settings > Actions > General > Workflow permissions and allow repository writes. The workflow commits its update history. Do not bypass organization restrictions or protected-branch policies.
  3. Open Actions > Refresh and deploy KE Observatory > Run workflow on main.
  4. After successful deployment, open the actual website link in Settings > Pages. Save that link and share it with your manager.

Example shape only: https://YOUR-USERNAME.github.io/ke-market-observatory/. No link has been activated in this package.

3. Check the first live update

Open Sources & updates in the published dashboard. Confirm which boards have a successful check. The first hosted run is the live API integration test; the build environment could not reach the APIs.

A failed source does not erase its records. It displays an error and retains last-good evidence. A green deployment does not mean every source succeeded.

Collection is scheduled daily at approximately 08:17 Riyadh time. An open browser checks for a new published dataset every five minutes. GitHub's schedule is best effort, not a guaranteed service.

4. Keep the reference useful

Edit data/curated.json for approved data and config/sources.json for additional supported job boards. Commit to main; the workflow rebuilds the same website.

The starter has 13 imported salary references and 8 Saudi posting references, including historic and unverified leads. Missing salaries remain Not disclosed. Missing experience requirements remain Not specified, never automatically Junior.

The six configured feeds are not an exhaustive LinkedIn search. Saved HTML, CSV and JSON exports are snapshots, not online collaborative copies.

Read README.md for API documentation, review rules, access limitations and the difference between global salaries and Saudi market pricing.
